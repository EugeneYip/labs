# Feature request hypotheses: Custody Calendar

Recorded during Comparative Research (2026-10-11). **None is to be built.** Status: *Hypothetical*, *Indirect* (public evidence of the need), *Direct* (a Custody Calendar user asked; none yet). Labs fit: *Yes* (static, local) or *No* (needs servers, accounts, or keys). A request becomes evidence only when a real user needs it.

| # | Idea | Status and signal | Labs fit | Main cost or risk |
